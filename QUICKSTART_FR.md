# ⚡ Démarrage Rapide - 2 Minutes

## 🎯 Pour Tester MAINTENANT

### 1. Démarrer (30 secondes)

```bash
pnpm dev
```

### 2. Ouvrir (5 secondes)

```
http://localhost:3000
```

### 3. Créer un Compte (30 secondes)

- Email: `test@example.com`
- Password: `Test1234`
- Name: `Test User`
- Cliquer "Create Account"

### 4. Créer des Todos (30 secondes)

- Ajouter 2-3 tâches
- ✅ Ça marche!

### 5. Tester l'Isolation (1 minute) ⭐

1. Cliquer "Logout"
2. Créer un 2ème compte: `user2@example.com` / `Pass1234`
3. **Vérifier**: Liste vide ← Important!
4. Se reconnecter: `test@example.com` / `Test1234`
5. **Vérifier**: Vos todos sont revenus!
